# ExportHUB Professional – Roadmap

- serverseitige Benutzerverwaltung
- Einladung / Erstpasswort
- Passwort-Reset
- Rollen-/Statusverwaltung
- Identity-Audit
- CSRF-Schutz für mutierende Admin-Aktionen
