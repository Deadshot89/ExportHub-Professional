# Firmen-Onboarding 0.6

1. Professional-Datenbank bereitstellen und `schema/postgres.sql` ausführen.
2. Umgebungsvariablen setzen: `PROFESSIONAL_DATABASE_URL`, `PROFESSIONAL_SESSION_SECRET`, `PROFESSIONAL_BOOTSTRAP_TOKEN`, `PROFESSIONAL_ENABLE_CONTROL_WRITES=true`.
3. `PROFESSIONAL_DATA_MODE=migration-read-only` und `PROFESSIONAL_ENABLE_WRITES=false` belassen.
4. Auf der Professional-Anmeldeseite „Ersteinrichtung“ öffnen.
5. Firma, Workspace-ID und ersten Firmen-Administrator anlegen.
6. Danach mit Workspace-ID + Anmeldename + Passwort anmelden.
7. Erst in einer späteren Version werden weitere Firmen über Plattformverwaltung/Einladungen angelegt.
